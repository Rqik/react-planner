# ДомПлан

Бесплатный редактор планировки дома на React, TypeScript и Vite. Работает в браузере без регистрации, ChatGPT, API-ключей и серверной части.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Откройте адрес, который покажет Vite, обычно http://localhost:5173.

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

Готовый статический сайт находится в `dist/`. Его можно размещать на обычном статическом хостинге.

## Структура

```text
src/
  main.tsx                    # Подключение React к странице
  app.tsx                     # Корневой компонент приложения
  features/planner/
    planner.tsx               # Компоновка редактора
    components/               # Шапка, инструменты, холст, свойства, шаблоны
    hooks/use-plan-editor.ts  # Состояние, история, жесты, импорт и экспорт
    model/                    # Типы проекта, шаблоны, проверка данных, геометрия
    types.ts                  # Типы объектов и инструментов
  components/ui/              # Общие UI-компоненты
  lib/                        # Общие вспомогательные функции
  styles/globals.css          # Стили приложения
public/                       # Статические ресурсы
```

Файлы и каталоги именуются в `kebab-case`, компоненты и типы — в `PascalCase`, функции и переменные — в `camelCase`. Импорты идут напрямую из модулей; алиас `@/` указывает на `src/`. TypeScript проверяет весь исходный код в строгом режиме и обнаруживает неиспользуемые импорты.

Компоненты отвечают за отображение и передают действия в `usePlanEditor`. Модель проекта не зависит от React. Для новой функции редактора добавляйте модель, обработчики и компоненты рядом в `features/planner`; общие элементы интерфейса храните в `components/ui`.

Для единообразного форматирования используйте `npm run format`; для проверки — `npm run format:check`.

## Хранение планов

План автоматически сохраняется в localStorage текущего браузера. Для переноса нажмите «Сохранить проект», затем «Открыть файл проекта» в другом браузере. Поддерживаются JSON-проекты и экспорт текущего этажа в SVG. Очистка данных браузера удаляет локальное сохранение, поэтому важные планы скачивайте в JSON.

Сохранён совместимый формат проектов и ключ `domplan-project`, поэтому ранее сохранённые планы продолжают открываться. Планировка является эскизом и не заменяет строительный проект.
