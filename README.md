# ДомПлан

Бесплатный редактор планировки дома на React, TypeScript и Vite. Работает в браузере без регистрации, ChatGPT, API-ключей и серверной части.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Откройте адрес, который покажет Vite, обычно http://localhost:5173.

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

Готовый статический сайт находится в `dist/`. Его можно размещать на обычном статическом хостинге.

## Структура

```text
src/
  main.tsx                    # Подключение React к странице
  app.tsx                     # Корневой компонент приложения
  features/planner/
    planner.tsx               # Компоновка редактора
    components/               # Шапка, инструменты, холст, свойства, шаблоны
    hooks/use-plan-editor.ts  # Состояние, история, жесты, импорт и экспорт
    model/                    # Типы проекта, шаблоны, проверка данных, геометрия
    types.ts                  # Типы объектов и инструментов
  components/ui/              # Общие UI-компоненты
  lib/                        # Общие вспомогательные функции
  styles/globals.css          # Стили приложения
public/                       # Статические ресурсы
```

Файлы и каталоги именуются в `kebab-case`, компоненты и типы — в `PascalCase`, функции и переменные — в `camelCase`. Импорты идут напрямую из модулей; алиас `@/` указывает на `src/`. TypeScript проверяет весь исходный код в строгом режиме и обнаруживает неиспользуемые импорты.

Компоненты отвечают за отображение и передают действия в `usePlanEditor`. Модель проекта не зависит от React. Для новой функции редактора добавляйте модель, обработчики и компоненты рядом в `features/planner`; общие элементы интерфейса храните в `components/ui`.

Для единообразного форматирования используйте `npm run format`; для проверки — `npm run format:check`.

## Хранение планов

План автоматически сохраняется в localStorage текущего браузера. Для переноса нажмите «Сохранить проект», затем «Открыть файл проекта» в другом браузере. Поддерживаются JSON-проекты и экспорт текущего этажа в SVG. Очистка данных браузера удаляет локальное сохранение, поэтому важные планы скачивайте в JSON.

Сохранён совместимый формат проектов и ключ `domplan-project`, поэтому ранее сохранённые планы продолжают открываться. Планировка является эскизом и не заменяет строительный проект.

## Выделение, группы и слои

Выделяйте несколько объектов через Shift + клик или рамкой на пустом месте. Для комнаты доступна кнопка «Выделить комнату с содержимым»: после этого нажмите «Группа», чтобы перемещать комнату вместе с мебелью. Группы сохраняются в JSON и localStorage. Чтобы изменить отдельный объект группы, сначала разгруппируйте её.

В панели «Слои» верхние строки соответствуют переднему плану. Порядок можно изменить перетягиванием строк, кнопками со стрелками или клавишами. Вставка и дублирование сохраняют взаимное расположение объектов и создают новую группу. Буфер копирования действует в открытом редакторе, в том числе между этажами.

| Клавиши                        | Действие                                     |
| ------------------------------ | -------------------------------------------- |
| Ctrl+C / Ctrl+V                | Копировать / вставить                        |
| Ctrl+X / Delete                | Вырезать / удалить выделение                 |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | Отмена / повтор                              |
| Ctrl+A / Ctrl+D                | Выделить всё / дублировать                   |
| Ctrl+G / Ctrl+Shift+G          | Группировать / разгруппировать               |
| Ctrl+] / Ctrl+[                | На один слой выше / ниже                     |
| Ctrl+Shift+] / Ctrl+Shift+[    | На передний / задний план                    |
| Escape                         | Снять выделение, отменить незавершённый жест |

На Mac используйте Command вместо Ctrl. При вводе текста и в диалогах команды редактора не перехватываются.

## Этажи и мебель

Этаж удаляется кнопкой корзины рядом с «+». Для непустого этажа требуется подтверждение; последний этаж остаётся в проекте. Удаление можно отменить.

На верхних этажах переключатели «Стены снизу» и «Комнаты снизу» показывают полупрозрачную подложку предыдущего этажа. Кнопка «Перенести внешние стены» копирует внешний контур комнат и стены, отмеченные как внешние; повторный перенос не добавляет дубликаты. Контуры переносятся как независимые стены: дальнейшие изменения одного этажа не изменяют другой автоматически.

У каждой категории мебели есть три варианта. Выбирайте вариант под кнопкой инструмента либо меняйте его в свойствах размещённого объекта. Поддерживаются прямые, Г- и П-образные лестницы и кухни; на плане кухни показаны столешница, мойка и варочная панель.
