# ДомПлан — локальная разработка

React + TypeScript + Vite. Сервер и аккаунт Sites не требуются.

Требуется Node.js 22.13+ (для Vite также подходит Node 20.19+).

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

```bash
npm run build
npm run preview
```

- `app/page.tsx` — редактор, состояние и взаимодействия.
- `app/globals.css` — оформление.
- `components/ui/` — используемые UI-компоненты.
- `public/` — статические файлы.

План хранится в localStorage текущего браузера. Для переноса со старого сайта нажмите там «Сохранить проект», а локально — «Открыть файл проекта». JSON-файл планировки не содержит исходный код.

Это копия приложения с переходом на обычный Vite; изменения локальной копии не публикуются автоматически в Sites.
